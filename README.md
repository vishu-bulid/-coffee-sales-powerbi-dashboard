## ☕ About The Project

The **Coffee Shop Sales Analytics Dashboard** is an interactive Business Intelligence project developed using **Microsoft Power BI**.

The purpose of this project is to transform raw coffee shop transaction data into meaningful and easy-to-understand business insights through interactive visualizations, KPIs, filters, and analytical charts.

The dashboard provides a complete overview of coffee shop sales performance, allowing users to explore revenue, orders, quantity sold, average order value, product categories, store locations, and sales trends.

This project demonstrates the practical application of **Data Analytics, Business Intelligence, Data Visualization, DAX, and Dashboard Development**.

---

# 🎯 Project Objectives

The major objectives of this project are:

- 📊 Analyze overall coffee shop sales performance
- 💰 Calculate and monitor total revenue
- 🧾 Analyze total number of orders
- 📦 Track total quantity of products sold
- 💵 Calculate Average Order Value
- ☕ Analyze sales across different product categories
- 🏪 Compare performance across store locations
- 📅 Analyze sales trends over time
- 🔍 Identify useful patterns in the sales data
- 📈 Present business information through interactive visualizations
- 🎛️ Allow users to explore the data using interactive filters

---

# 📊 Dashboard KPIs

The dashboard contains important Key Performance Indicators that provide a quick overview of business performance.

### 💰 Total Revenue

Represents the total revenue generated from all transactions.

### 🧾 Total Orders

Shows the total number of transactions recorded in the dataset.

### 📦 Total Quantity Sold

Represents the total number of products/units sold.

### 💵 Average Order Value

Shows the average revenue generated per transaction.

# 🔍 Dashboard Features

## ☕ Product Category Analysis

The dashboard analyzes sales performance across different coffee shop product categories.

This helps understand which categories contribute significantly to overall revenue and sales volume.

---

## 🏪 Store Location Analysis

Sales performance is analyzed across different store locations.

This allows comparison of revenue generated by different stores and provides a clear view of location-wise performance.

---

## 📅 Sales Trend Analysis

The dashboard includes time-based analysis to understand how sales performance changes over time.

Users can explore sales trends and identify changes in revenue and order activity.

---

## 📈 Revenue Analysis

Revenue is analyzed using different dimensions such as:

- Product Category
- Store Location
- Time Period
- Product Performance

This makes it easier to understand where revenue is being generated.

## 🎛️ Interactive Filters

The dashboard provides interactive slicers that allow users to filter the report dynamically.

🏪 **Store Location**

# 📌 Dataset Information

The project is based on a coffee shop transaction dataset containing detailed information about individual sales transactions.

### Important Columns

| Column | Description |
|---|---|
| `transaction_id` | Unique transaction identifier |
| `transaction_date` | Date of transaction |
| `transaction_time` | Time of transaction |
| `transaction_qty` | Quantity of products sold |
| `store_id` | Unique store identifier |
| `store_location` | Store location |
| `product_id` | Unique product identifier |
| `unit_price` | Price per unit |
| `product_category` | Category of the product |
| `product_type` | Type of product |
| `product_detail` | Detailed product name |
